**🏏 Cricket World Cup 2023 Analytics**

**📊 Project Overview**
This project delivers an interactive Power BI dashboard analyzing the ICC Cricket World Cup 2023. The dataset, sourced from Kaggle, captures match-level and player-level statistics across all teams and venues. The goal of this project is to provide actionable insights into team performances, player contributions, and tournament trends through dynamic visual storytelling.

**🎯 Objectives**
- Explore and visualize key tournament metrics such as total runs, wickets, strike rates, and win percentages.
- Compare team performances across different matches, venues, and opponents.
- Analyze player statistics to identify top batsmen, bowlers, and all-rounders.
- Highlight venue trends (average scores, toss impact, win ratio by batting/fielding first).
- Enable interactive filters for users to slice data by team, player, or match type.

**⚙️ Tools & Technologies**
Power BI Desktop – Dashboard development and visualization.
Kaggle Dataset – Source for match and player data.
Excel / CSV – Data cleaning and transformation prior to import.
DAX Measures – Used for dynamic KPIs like Run Rate, Economy, and Strike Rate.

**📈 Key Insights**
Identified top-performing teams based on average run rate and win consistency.
Uncovered player-level trends such as most runs scored, wickets taken, and strike rate performance.
Evaluated how toss decisions and venue conditions influenced match outcomes.

**📁 Dataset Source**
Kaggle – ICC Cricket World Cup 2023 Dataset: https://www.kaggle.com/datasets/maulikpatel1930/cricket-world-cup-2023/data

**💡 Outcome**
This dashboard provides a comprehensive analytical view of the 2023 Cricket World Cup, enabling users to interactively explore performances, compare player stats, and discover patterns that shaped the tournament’s results.
